# pasta — تحديثات

مستودع التوزيع لبرنامج **pasta** لإدارة المطاعم. لا يحوي كوداً مصدرياً — ملفات التنصيب والتحديث فقط.

## التنزيل

أحدث إصدار: [الإصدارات](../../releases/latest)

| | |
|---|---|
| برنامج الحاسوب | `pasta Setup x.y.z.exe` — ويندوز 10 فما فوق |
| تطبيق الهاتف | `pasta-caller-x.y.z.apk` — أندرويد 8 فما فوق |

## آلية التحديث

يقرأ التطبيقان الملف [`latest.json`](latest.json) ويقارنان نسختهما بما فيه،
ثم ينزّلان الملف ويتحقّقان من بصمة SHA-256 قبل التثبيت.
